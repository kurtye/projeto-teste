# **App Name**: Hell Let Loose BR

## Core Features:

- Global Player Rankings: Display global player rankings based on various in-game statistics.
- Detailed Player Profiles: Allow users to search for and view detailed profiles of individual players, including combat statistics and historical performance.
- Ranking Filters: Implement filters to sort rankings by server, time period, and specific in-game metrics.
- Leaderboard data extraction: Extract game play leaderboard data from the Hell Let Loose servers. This background job runs continuously to keep leaderboard current. It includes an AI tool to remove cheaters.

## Style Guidelines:

- Primary color: Olive green (#808000), mirroring the game's military setting.
- Background color: Dark charcoal gray (#333333) for an immersive dark theme.
- Accent color: Subtle orange (#FFA500) highlights for interactive elements and key information.
- Body text: 'Inter', sans-serif, for readability in a data-heavy interface.
- Headline text: 'Space Grotesk', sans-serif, to add a modern, impactful look.
- Use military-themed icons with a minimalist design style.
- Prioritize clear data presentation and intuitive navigation.
